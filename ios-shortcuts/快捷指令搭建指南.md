# iOS 快捷指令 + Scriptable 搭建指南

目标：手机上**选照片 → 点一下 → 自动填表嵌图**，全程零 AI 开销。

架构：快捷指令负责（选照片 → OCR 水印 → 选厕所 → 存照片）；
Scriptable 脚本负责（连金山文档 MCP → 定位行 → 填5格 → 嵌 DISPIMG → 验证弹窗）。

---

## 第一步：安装 Scriptable 并导入脚本

1. App Store 安装 **Scriptable**（免费）
2. 手机浏览器打开本仓库的 `ios-shortcuts/toiletFill.js`，**全选复制**
3. 打开 Scriptable → 右上角「+」→ 粘贴 → 改名为 **toiletFill** → 完成保存
4. 首次配置：
   - 打开 `CONFIG` 里的 `writeTarget`：`"copy"`（测试用副本）／`"official"`（正式表）
   - Scriptable 会请求 iCloud 和网络权限，全部允许
5. 单独运行一次 toiletFill → 弹「WPS 授权」→ 点「打开授权页」→ 浏览器确认 → 自动保存 Token（约一年有效）

## 第二步：iCloud Drive 建中转文件夹

在「文件」App → iCloud Drive → **Scriptable** 文件夹里新建文件夹 **ToiletUpload**
（快捷指令存照片到这，脚本从这读）

## 第三步：搭建快捷指令

打开「快捷指令」App → 右上角「+」新建，依次添加以下动作（动作名以 iOS 中文界面为准）：

| # | 动作 | 设置 |
|---|------|------|
| 1 | **选择照片** | 「选择多项」关闭；或改用「拍摄照片」直接拍 |
| 2 | **从图像提取文字**（提取文本） | 输入=选择照片的结果 |
| 3 | **匹配文本**（正则） | 文本=提取的文字；正则填：<br>`([01]?\d)-([0-3]?\d)-(\d{4})\s+([01]?\d):([0-5]\d):[0-5]\d`<br>⚠️ 打开「正则表达式」开关 |
| 4 | **文本**（拼日期） | 内容：`匹配文本的第1组.第2组`<br>（用「匹配文本组」取第 1、2 组，中间打一个点） |
| 5 | **替换文本** | 输入=上一步文本；查找 `^0`（开正则）；替换为空 → 得到 `10.31` |
| 6 | **文本**（拼时间） | `第4组:第5组` → 得到 `9:36`（可能带前导零） |
| 7 | **替换文本** | 查找 `^0`（开正则）替换为空 → `9:36` |
| 8 | **从菜单中选取** | 提示「楼层」：一、二、三、四、五 |
| 9 | **从菜单中选取** | 提示「位置」：东边、中庭、西边 |
| 10 | **从菜单中选取** | 提示「厕所」：男厕、女厕 |
| 11 | **文本**（拼表名） | `菜单结果8楼菜单结果9菜单结果10` → 如 `二楼中庭男厕` |
| 12 | **存储文件** | 输入=选择照片的照片；服务=iCloud Drive；路径=`Scriptable/ToiletUpload`；文件名=`photo`；「询问存储位置」关闭；覆盖=true |
| 13 | **URL** | `scriptable:///run?scriptName=toiletFill&date=步骤5结果&time=步骤7结果&sheet=步骤11结果`（用变量填充） |
| 14 | **打开 URL** | 输入=上一步 |

最后：给快捷指令命名（如「厕所巡查」）→ 添加到主屏幕。可设置「运行时显示通知」。

> iOS 17.4+ 的「提取文字」动作在部分系统叫「从图像提取文本」；「匹配文本组」动作名是「获取文本组」（Match Text 的 Get Group）。找不到组动作时，也可以在正则里用整体匹配后用「拆分文本」处理，或按上面变量的「组」下拉选择。

## 第四步：日常使用（每条记录约 10 秒）

1. 点主屏幕图标（或分享照片到快捷指令）
2. 确认照片（水印要清晰、含日期时间）
3. 依次点楼层/位置/厕所
4. 等 5-15 秒，弹出「✅ 填报成功」

## 切换测试表 / 正式表

Scriptable 里打开 toiletFill，改 CONFIG：

```js
writeTarget: "copy"      // → 测试（厕所巡查记录表[副本]）
writeTarget: "official"  // → 正式（厕所巡查记录表）
```

## 故障排查

| 现象 | 处理 |
|---|---|
| 弹「未配置 Token」 | 单独运行一次 toiletFill 走授权 |
| 「找不到照片」 | 检查快捷指令「存储文件」路径必须是 Scriptable/ToiletUpload |
| OCR 时间不对 | 手拍水印确保清晰；快捷指令里可加「询问输入」人工改时间 |
| 「第N次已有记录」 | 该行已填过，去表格确认 |
| 「图片插入未持久化」 | 网络波动，重跑一次（会重复弹确认，注意别重复填行） |
| 弹「❌ 出错了」 | 错误信息已截取显示；截图发回来排查 |

## ⚠️ 安全提醒

- Token 存在手机 Keychain 里，不要把带 Token 的脚本截图/分享
- 正式表写入权限依赖飞神的共享设置，首次写正式表若报权限错误需联系他开编辑权
